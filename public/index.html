# IT Onboarding Guide — New Employee Setup ## Overview This guide covers the complete onboarding process for new employees including Active Directory setup, Office 365 configuration, and workstation preparation. ## Prerequisites - Domain Administrator credentials - Office 365 admin access - Standard software installer package ## Step 1 — Create Active Directory Account 1. Open Active Directory Users and Computers 2. Navigate to the appropriate OU for new users 3. Right-click and select New → User 4. Enter first name, last name, and username (firstname.lastname) 5. Set temporary password and require change at next login 6. Add user to standard security groups: Domain Users, VPN-Users, Office365-Licensed ## Step 2 — Configure Office 365 Email 1. Log into Microsoft 365 Admin Center 2. Go to Users → Active Users → Add User 3. Assign E3 or appropriate license 4. Set primary email address to match AD username 5. Add to relevant distribution groups ## Step 3 — Workstation Setup 1. Join workstation to domain 2. Install standard software package 3. Configure VPN client with user credentials 4. Set up antivirus and confirm definition update ## Step 4 — First Login Walkthrough 1. Have user log in with temporary password 2. Guide through password change requirements 3. Confirm email access in Outlook 4. Test VPN connection 5. Provide IT support contact information ## Notes - IT Support: 555-1234 - All setup must be completed before employee start date
